# Snare Studio

Aplicación académica de procesamiento digital de señales para analizar resonancias y ecualizar audio de redoblante. La interfaz permite trabajar con la demostración integrada, un archivo WAV o una entrada de audio en tiempo real.

| Si querés… | Empezá aquí |
| --- | --- |
| Revisar o modificar el programa en MATLAB | [SnareStudio-Source](SnareStudio-Source/README.md) |
| Usar el ejecutable de Windows | [Descargas en GitHub Releases](https://github.com/snarestudioproyecto/SnareStudio/releases) · [Guía de instalación](docs/Windows.md) |

La edición de código fuente arranca con `PRINCIPAL.m`. El ejecutable Windows V4.1 disponible para revisión procede de otra compilación del proyecto. Puede presentar diferencias de interfaz y comportamiento con respecto al código de esta entrega.
